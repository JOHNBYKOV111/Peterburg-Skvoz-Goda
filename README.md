Полнофункциональный промо для онлайн-курса акварельной живописи, посвященного архитектурным пейзажам Санкт-Петербурга. Проект сочетает в себе элегантный дизайн с современными интерактивными элементами.

Цели проекта:
Создание продающей страницы для арт-курса,
Демонстрация работ преподавателя через интерактивную галерею,
Упрощение процесса записи на курс с понятным представлением тарифов,
Адаптация под все устройства для максимального охвата аудитории.

Ключевые особенности:
Интерактивная VIP-галерея,
Кастомная модальная галерея с плавными анимациями,
Динамическая подсветка картин с эффектом пульсации,
Навигация с миниатюрами и preview,
Ультра-плавное появление изображений.

Динамическая система тарифов:
Три тарифных плана с визуальным выделением VIP-варианта,
Конвертер валют в реальном времени (₽/$/€),
Визуализация бонусов через анимированные "золотые монеты",
Интерактивное сравнение возможностей разных пакетов.

Продвинутые визуальные эффекты:
Кастомные оранжевые подсветки с анимацией glow-pulse,
Интерактивные иконки с эффектами наведения,
Адаптивные изображения с lazy-load подходом,
Анимация появления контента при скролле.

Пользовательский опыт:
Полностью адаптивный дизайн (mobile-first подход),
Интуитивная навигация с плавным скроллом,
FAQ-аккордеон с анимированным раскрытием,
Визуализация материалов курса с интерактивными блоками.

Технологический стек:
HTML5 (семантическая разметка),
CSS3 (Flexbox, Grid, анимации, медиа-запросы),
JavaScript ES6+ (нативный DOM API),
jQuery 3.5.1 (для совместимости и упрощения кода).

Библиотеки и фреймворки:
Bootstrap 4.5.2,
Font Awesome 6,
Google Fonts.

Оптимизация:
Адаптивные изображения,
Минимизированные CSS/JS,
Оптимизированная загрузка ресурсов.

Адаптивность:
Mobile-first подход,
Планшеты,
Кастомные медиа-запросы для каждого компонента.

Запуск проекта: Скачать, установить, запустить.
